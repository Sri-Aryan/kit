What a finding looks like.

No "consider reviewing your input handling". A location, a reference, a fix and a test.

CRITICAL Example

SQL query built from request input

Location
src/routes/orders.ts:42
References
OWASP A03:2021 · CWE-89
Evidence
req.query.status reaches db.query() via string concatenation
Fix
- const rows = await db.query(`SELECT * FROM orders WHERE status = '${req.query.status}'`);
+ const rows = await db.query("SELECT * FROM orders WHERE status = $1", [req.query.status]);
Regression test
// orders.security.test.ts
it("treats status as data, not SQL", async () => {
  const res = await get("/orders?status=' OR '1'='1");
  expect(res.body).toHaveLength(0);
});

FAQ

Questions, answered.

Does my code get sent anywhere?

No. Scans run as local Python and Node scripts. There's no telemetry, no account and no network call. Your agent reads the code the same way it already does when you work with it.

Which agents does it work with?

Claude Code and OpenAI Codex out of the box, plus any agent that reads the open Agent Skills format from ~/.agents/skills/. Each skill is a plain folder with a SKILL.md, so you can also paste one into any agent's instructions.

What languages and frameworks are supported?

Skills check security concepts rather than framework-specific patterns, like "is this query parameterized?" or "is ownership checked on this endpoint?", so they work across stacks.

Do I need Semgrep?

No. It's optional. /sk-api uses it when it's installed. Everything else needs only Node.js 18+ and Python 3.

How do I suppress a risk we've accepted?

Add securitykit-ignore: CHECK-ID in a comment on or above the line, or add an entry with a reason (and optional expiry) to .securitykit/ignore.json. Entries without a reason are ignored.

Will /sk-fix change code without asking?

No. It works through findings one by one, proposes each fix, applies only the ones you approve, and re-verifies afterwards.

Is this a penetration test?

No. SecurityKit helps you find and fix common weaknesses; it is not a penetration test or a certification. A clean report is not a guarantee of security.

How do updates work?

Run npx github:getsecuritykit/kit update. Files you've edited locally are kept and listed, so your customizations aren't overwritten.
